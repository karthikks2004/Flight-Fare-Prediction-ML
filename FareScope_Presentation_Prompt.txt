### SLIDE 7: ML Pipeline & Preprocessing (Light Theme)
- Category Tracker: "Methodology"
- Main Title: "ML Pipeline & Preprocessing"
- Layout: Horizontal flow block on top, detail card below.
- Top Flow Blocks:
  - Load Data (300K records, Pandas CSV) → EDA (Matplotlib, Seaborn plots) → Preprocessing (IQR outlier removal, One-Hot + Ordinal Encoding) → Train Models (5 algorithms, 80/20 split) → Evaluate (MAE · RMSE · R² score) → Deploy (Flask web app, Prediction page)
- Bottom Detail Card:
  - Heading: "Preprocessing Details & Feature Engineering"
  - Bullet Points:
    - Stops (zero=0, one=1, two_or_more=2) and Class (Economy=0, Business=1) mapped ordinally.
    - Departure/Arrival times mapped as sequential daily slots (Early Morning, Morning, etc.).
    - Nominal columns (airline, source_city, destination_city) encoded using One-Hot Encoding (total 21 features).
    - Outliers removed using the IQR method on ticket price, excluding 123 extreme price records.
    - StandardScaler applied to scale numeric attributes (duration, days_left) to standard format.

- Bottom Left Card (Dark Background):
  - "NO"
- Bottom Right Card (Explanation):
  - Heading: "Why not?"
  - Bullet Points:
    - days_left is a critical predictive feature (1.5% overall importance score).
    - Airlines apply dynamic pricing: as booking capacity drops near departure, ticket price rises.
    - Model predicts low early-bird fare for a booking 45 days ahead (avg ~₹19,105).
    - Model predicts a significantly higher last-minute fare for booking 2 days ahead (avg ~₹25,630).
    - The Flask app shows both prices side-by-side, proving the model captures this dynamic correctly.
